# 📦 Barcode Scanner with Image Capture

A Python tool to scan 1D barcodes from images, display the decoded information, and highlight the barcode visually.

---

## 🧰 Features

- 📸 Load and process barcode images
- 🧠 Decode standard 1D barcodes (Code128, Code39, EAN, etc.)
- 🖼️ Display detected barcodes with bounding boxes
- 📝 Print barcode data to the terminal
- 🧪 Lightweight and runs in a virtual environment

---

## 🔧 Requirements

- Python 3.x
- OpenCV
- pyzbar
- ZBar (system dependency)
